MinGW-w64 runtime libraries (Windows installer only)

The Windows installer ships the C++ runtime libraries of the MinGW-w64
toolchain next to the application:

  libstdc++-6.dll, libgcc_s_seh-1.dll
    GPL version 3 with the GCC Runtime Library Exception version 3.1.
    Full texts: licenses/COPYING3.txt and licenses/COPYING.RUNTIME.txt in
    the installation directory. The Runtime Library Exception permits
    distributing these runtime libraries together with this MIT-licensed
    application.

  libwinpthread-1.dll
    MIT and BSD licenses; full text: licenses/COPYING.winpthreads.txt in
    the installation directory.

Corresponding source code for these libraries is available from the Fedora
MinGW toolchain source packages (https://src.fedoraproject.org/rpms/mingw-gcc)
and upstream (https://gcc.gnu.org, https://www.mingw-w64.org).
