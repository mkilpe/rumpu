Rumpu - Release Notes
=====================


0.1.0-alpha1 (First alpha)
--------------------------
Initial alpha release.

Song
    - Songs built from sections, tracks and instruments
    - Sections with editable name and length
    - Reorderable sections and section cloning
    - Per-track volume, mute and gain
    - Editable track names
    - Per-song and per-beat random offset / volume
    - Choke groups

Editing
    - Section view and section info view
    - Zoomable timeline
    - Play / stop controls with play cursor
    - New song, add track, add instrument and export dialogs
    - About dialog with license and authors
    - Track header context menu

Audio
    - ALSA playback on Linux
    - DirectSound playback on Windows
    - WAV export, including 32-bit float

Project files
    - Save and load .spd project files
    - Bundled demo songs

Platform
    - Linux and Windows builds
    - Windows installer
    - Command-line arguments
    - Version number reporting


0.1.1
-----
    - Play cursor fix
    - Per-track volume
    - Play time fix on Wine


0.1.2
-----
    - 24-bit audio support fix
    - Experimental undo
    - Smoother dialog flow across most dialogs
    - Import multiple WAV files at once
    - Randomization across multi-sample instruments
    - Follow-cursor option in timeline
    - Mouse wheel restricted to zoom (no scroll)
    - Saner default dialog sizes
    - Track context menu: clear track and apply pattern (1-4 bar pattern editor with split/divide/clear/choke)


0.1.3
-----
    - Fix crash on export; export uses the correct sample rate
    - Fix peak normalisation of silent songs
    - Per-track mute and volume applied correctly; improved tempo and volume slides
    - Negative timing offsets handled correctly
    - Hardened .spd loading and saving (value validation) and WAV loading
    - Re-use already loaded samples when loading instruments
    - DirectSound: frames-versus-bytes size fix and missing features implemented;
      ALSA: frames-versus-samples fix; small leak fixes in both backends
    - Dialog session handling and minor GUI fixes
    - Third-party licences bundled with the Windows installer; installer build fixes
    - Out-of-source CMake builds with presets; GitHub CI builds and tests Linux and
      Windows (cross-compiled, tests run under Wine) and publishes the installer on tags


0.1.4
-----
    - Log and GUI layout files (rumpu.log, imgui.ini) are written to the user's
      own directory instead of the working directory: AppData\Local\Rumpu on
      Windows, where the install directory is read-only for standard users;
      ~/.local/state/rumpu and ~/.config/rumpu on Linux
    - Version string ended in "+unknown" in CI-built releases: CI now fails when
      the commit hash cannot be determined, and local builds re-read the hash when
      the checked-out commit changes


0.1.5
-----
    - The Secure Path base libraries (logging, event loop, serialisation, audio
      backends) come from the securepath git submodule instead of in-source copies;
      their audio tests moved there as well
    - The Windows installer build runs the full test suite first, securepath's
      suites included, and is not produced when any test fails
